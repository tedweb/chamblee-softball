Chamblee High School Softball

Electro-Mech Scoreboard Controller — Game-Day Quick Reference

GREEN = RUNS
BLUE = HITS / COUNTS
RED = ERRORS / CAUTION
YELLOW = INNING
PURPLE = CORRECTIONS

Most Important Rule

TOP = VISITOR batting   |   BOTTOM = CHAMBLEE batting

The controller decides which team receives runs, hits, errors, and pitches based on the current half-inning. Always verify TOP/BOTTOM before pressing a scoring button.

1. Start a New Game

  1. Turn on scoreboard power and connect the controller.
  2. If the display asks RESTORE GAME?, choose 0 then ENTER.
  3. Press NEW GAME → 1 → ENTER.
  4. Press INC. INNING TOP/BOT once.
  5. Verify the display shows T01.

T01 = Top of the 1st, Visitors batting.

2. Change Half-Innings

At the end of every half-inning:

INC. INNING TOP/BOT

The sequence should be:

T01 → B01 → T02 → B02 → T03 → B03 ...

Important: Enter the final run, hit, or error before advancing the inning.

3. Add a Run

When a run scores:

RUNS +1

The run goes automatically to the team currently batting.

T03 → Visitors get the run.
B03 → Chamblee gets the run.

4. Record a Hit

When the official scorer rules a hit:

HITS +1

The hit goes automatically to the team currently batting.

A hit and a run are separate. If both happen, enter both.

5. Record an Error

For a defensive error:

ERRORS +1

The error is charged automatically to the team NOT batting.

Do not change innings first. That can charge the error to the wrong team.

6. Assign Error to a Position

ASSIGN ERROR → position number → ENTER
#Position#Position
1Pitcher6Shortstop
2Catcher7Left Field
3First Base8Center Field
4Second Base9Right Field
5Third Base

Do not also press ERRORS +1. Assign Error already adds the error total.

7. Balls, Strikes & Outs

BALL +1 increments balls.

STRIKE +1 increments strikes.

OUT +1 increments outs.

Follow the umpire's count. After the third out, finish any scoring entries, then advance the half-inning.

8. Set the Batter Number

SET BATTER → player number → ENTER

Example for player #13:

SET BATTER → 1 → 3 → ENTER

9. Pitch Count

PITCHES +1

The pitch is credited to the team NOT batting, because that team is on defense.

Top inning: Chamblee pitcher gets the pitch.
Bottom inning: Visitor pitcher gets the pitch.

10. Correct the Total Score

SET TOTAL RUNS
  1. Enter Visitor / Top score → ENTER.
  2. Enter Chamblee / Bottom score → ENTER.

Example, Visitors 3 — Chamblee 5:

SET TOTAL RUNS → 3 → ENTER → 5 → ENTER

11. Correct Hits or Errors

Hits:

SET TOTAL HITS → Visitor total → ENTER → Chamblee total → ENTER

Errors:

SET TOTAL ERRORS → Visitor total → ENTER → Chamblee total → ENTER

12. Correct the Inning

SET INNING TOP/BOT → inning → ENTER

Then choose:

0 = TOP    |    1 = BOTTOM

Bottom of 5th:

SET INNING TOP/BOT → 5 → ENTER → 1 → ENTER

Top of 6th:

SET INNING TOP/BOT → 6 → ENTER → 0 → ENTER

13. Correct Runs for One Inning

SET RUNS / INNING → inning → ENTER

Then enter the Visitor/Top runs and the Chamblee/Bottom runs.

Example: 4th inning, Visitors 2 and Chamblee 1:

SET RUNS / INNING → 4 → ENTER → 2 → ENTER → 1 → ENTER

14. Cancel an Entry

If you press a SET button accidentally and the controller is waiting for a value:

CLEAR

Think of CLEAR as Cancel / Back.

15. Clock

Start/Stop: CLOCK ON/OFF

Set clock:

SET CLOCK → time → ENTER

Example for 5:30:

SET CLOCK → 5 → 3 → 0 → ENTER

Count direction: stop clock, press CLOCK UP/DOWN, then 1 for up or 0 for down.

16. If Everything Looks Wrong

Do not immediately press NEW GAME. Compare the scoreboard to the official scorebook, then correct only what is wrong:

✓ Current inning

✓ Top or Bottom

✓ Visitor total runs

✓ Chamblee total runs

✓ Hits

✓ Errors

Use SET INNING TOP/BOT, SET TOTAL RUNS, SET TOTAL HITS, SET TOTAL ERRORS, and SET RUNS / INNING as needed.

17. Never Press NEW GAME During Live Play

NEW GAME → 1 → ENTER resets game information.

Use it only before a game or when intentionally starting over.

18. Between-Innings 5-Second Check

  • Correct inning?
  • TOP/BOTTOM correct?
  • Visitor score correct?
  • Chamblee score correct?
  • Outs reset/correct?
  • Ball/strike count correct?
  • Pitch count reasonable?

19. Simple Game Routine

Before first pitch: New Game → advance to T01 → verify 0–0.

During play: update balls, strikes, hits, runs, outs, errors, and pitches.

After third out: finish scoring entries → verify score → advance half-inning.
