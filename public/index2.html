Electro-Mech Scoreboard Quick Reference

Linescore Baseball / Softball Controller Operations
Console Tip: When numeric entry is required, press the sequence clearly and confirm with ENTER. If the system asks "RESTORE GAME?" on startup, press 0 then ENTER for a brand new game.

1. Game Setup & Resets

  • Start New Game: Press NEW GAME → 1 → ENTER. Resets all innings, runs, hits, errors, pitch counts, and counts to zero.
  • Power Outage Recovery: If power turns off mid-game, choose 1 → ENTER when prompted with RESTORE GAME? to restore live scores.

2. Inning Controls

  • Advance Half-Inning: Press INC. INNING TOP / BOT to step forward (Top 1st → Bot 1st → Top 2nd).
  • Set Specific Inning: Press SET INNING TOP / BOT → [Inning #] → ENTER.

3. Count & Outs

  • Add Ball: Press BALL +1 (resets to 0 automatically after 4).
  • Add Strike: Press STRIKE +1 (resets to 0 automatically after 3).
  • Add Out: Press OUT +1 (resets to 0 automatically after 3).
  • New Batter (Clear Count): Press SET BATTER to clear balls & strikes for the next hitter.

4. Runs, Hits & Errors

  • Add 1 Run: Press RUNS +1 (adds +1 to the current inning and updates Total Runs).
  • Add 1 Hit / Error: Press HITS +1 or ERRORS +1.
  • Set Total Manually: Press SET TOTAL RUNS (or HITS / ERRORS) → [Number] → ENTER.
  • Set Inning Runs Manually: Press SET RUNS / INNING → [Number] → ENTER.
  • Flash Hit/Error Light: Press CLEAR / FLASH HIT or ENTER / FLASH ERROR.

5. Pitch Count & Clock

  • Add Pitch: Press PITCHES +1 to increment current pitcher's count.
  • Start / Stop Clock: Press CLOCK ON / OFF (red button).
  • Set Clock Time: Press SET CLOCK → [Time] → ENTER.
  • Sound Horn: Press HORN.
